A short Python program (standard library only) that writes a single
187-character text to /output/entry.txt — a rusted tin box under the
third stone from the gate, a photograph of a house never seen, and the
reader's own name on the back. One concrete image, one unanswered
question; the curiosity does the rest.

## Run it

```sh
python3 main.py   # writes /output/entry.txt (187 characters)
```
